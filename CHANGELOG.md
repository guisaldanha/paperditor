## [1.0.0] - 2025-05-20

### Added
- Initial release of Paperditor.
- WYSIWYG Markdown editing powered by TipTap.
- Dual mode: rich editor and raw Markdown source.
- Light and Dark themes with persistent preference.
- Full formatting toolbar: headings (H1–H6), bold, italic, strikethrough, highlight, inline code.
- Superscript and subscript support.
- Bullet, ordered, and task (checkbox) lists.
- Blockquote, fenced code blocks with syntax highlighting, and horizontal rule.
- Hyperlink and inline image insertion.
- Table management: insert, add/remove rows and columns, toggle header row/column/cell.
- Text alignment: left, center, right, justify.
- Footnote support with GFM-compatible round-trip.
- Emoji picker with categorized browsing and shortcode conversion.
- Find bar (`Ctrl+F`) for in-document search.
- Open, Save, Save As `.md` and `.markdown` files.
- Export to PDF.
- Print support.
- File associations for `.md` and `.markdown` files.
- Single-instance mode: opening a second file focuses the existing window.
- Unsaved-changes indicator (`•`) in the window title bar.
- Native application menu with full keyboard shortcuts.
- Windows installer built with electron-builder (NSIS).
