# Paperditor Privacy Policy

_Last updated: August 7, 2026_

Paperditor is a desktop Markdown editor built with Electron. This policy explains, plainly, how the application handles user data.

## Summary

Paperditor **does not collect, store, transmit, or share any personal or usage data**. It runs entirely offline, on your computer.

## What data the application accesses

Paperditor only reads and writes the files you explicitly open or save, using your operating system's native file dialogs. These files stay on your device at all times and are never sent to any server.

## Internet connection

The application makes no network calls. It has no telemetry, analytics, crash reporting, automatic update mechanism, or integration with third-party services.

## Accounts and sign-up

Paperditor does not require login, sign-up, or any form of user identification.

## Sharing with third parties

Since no data is collected, no data is shared with third parties.

## Children

The application is not directed at children, but its use by them is not prohibited. Since it does not collect data from any user, it does not collect data from minors either.

## Changes to this policy

Should this policy change — for example, if a future version of the application adds an online feature — the "last updated" date at the top of this page will be revised and the changes will be described here.
